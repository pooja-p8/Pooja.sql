College Demo Database

Overview

This SQL project creates a simple College Database using MySQL. It stores information about departments, students, courses, and enrollments.

Tables

- Department – stores department details.
- Student – stores student information.
- Course – stores course details.
- Enrollment – stores students' course and semester information.

SQL Concepts Used

- "CREATE DATABASE"
- "CREATE TABLE"
- "INSERT INTO"
- Primary Key
- Foreign Key
- "UNIQUE"
- "NOT NULL"
- "CHECK"
- "SHOW TABLES"
- "DESC"

Purpose

The project demonstrates how to create and connect multiple tables using primary and foreign keys and how to insert records into a relational database.
